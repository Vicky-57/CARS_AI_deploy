2. Recommended Tech Stack & Integration Method
Every tool below is connected to n8n through either a native node or a direct API call. This table shows exactly how each piece talks to the others.
Tool
Connects via
Integration Detail
HubSpot Free CRM
n8n HubSpot node (OAuth 2.0 / Private App)
Native n8n node — create/update contacts, deals, tasks, notes. Real-time webhook triggers are limited on Free tier, so changes are detected via scheduled polling (every 5 min) instead of instant push triggers.
Gmail
n8n Gmail node (OAuth 2.0)
Native n8n node — trigger on new email, send email, label/archive. Used for inbound lead capture and outbound logging.
Google Drive
n8n Google Drive node (OAuth 2.0)
Native n8n node — create folders, upload files, move/rename. Used to build and maintain the client/deal folder structure automatically.
WhatsApp Business
n8n WhatsApp Business Cloud API node / webhook
Official Meta Cloud API via n8n's WhatsApp node — inbound messages arrive via webhook, outbound replies sent via API call. Requires Meta Business verification before webhook goes live.
Claude API
n8n HTTP Request node (Anthropic API)
No native n8n node — calls Anthropic's /v1/messages endpoint directly via HTTP Request node. Used for summarization, classification, drafting, and the daily brief.
Whisper / Transcription
n8n HTTP Request node (OpenAI Whisper API)
Voice notes forwarded via webhook, sent to Whisper API for transcription, text returned to n8n for further processing by Claude.
Google Sheets (optional)
n8n Google Sheets node (OAuth 2.0)
Used only if lightweight reporting beyond HubSpot's dashboard is needed.
2.1 Important Technical Notes
HubSpot Free fully supports n8n's native HubSpot node for creating/updating contacts, deals, tasks, and notes — zero issues for this use case
All standard read/write operations work on the Free tier with no restrictions
Real-time webhook triggers (e.g. "the moment a deal moves to Won, do X") require HubSpot Professional/Enterprise
Workaround: n8n Schedule Trigger polls HubSpot every 5 minutes instead of instant push — not a dealbreaker for a 1-person operation
HubSpot requires OAuth 2.0 or Private App tokens for all API access as of 2026 — old-style API keys no longer work
This is a one-time setup detail during Week 1, not an ongoing limitation
WhatsApp connects via n8n's WhatsApp Business Cloud API node — inbound via webhook, outbound via API call
Requires Meta Business verification to be completed before the webhook can go live
Claude has no native n8n node — it is called directly via the HTTP Request node against the Anthropic API
