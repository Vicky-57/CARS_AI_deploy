🚨 THE ONE BIG PROBLEM
Claude Cowork scheduled tasks ONLY run while the laptop is switched on, awake, and the Claude Desktop app is open. If the laptop is closed, asleep, or off at 7am — the morning task simply does not run. Cowork also has no memory between sessions — every run starts completely fresh. This means the original COWORK plan is not truly automatic unless one computer is left on 24/7.
	

THE FIX:
→  Move the automation engine from Claude Cowork to n8n. n8n never sleeps, never closes, and runs 24/7 regardless of any laptop.
→  Claude is still used for all the "thinking" — summarizing, drafting, extracting tasks — but n8n is what triggers it and keeps things running on schedule.

THE FINAL PLAN
	

1. CRM Foundation
HubSpot free account. Stores all contacts, companies, deals, tasks, notes. n8n and Claude both read/write to it.
	

2. Sales & Pipeline
HubSpot built-in Kanban pipeline. n8n polls HubSpot every 5 minutes (Free tier has no real-time webhooks) and flags deals with no activity. Claude writes the follow-up message.
	

3. Email
Gmail and Outlook connected through n8n (always-on server). New emails trigger n8n, which sends the content to Claude to summarise and match to the right HubSpot contact.
	

4. WhatsApp
WABA number connected to n8n through Wassenger (Enterprise plan). n8n catches every message instantly, Claude reads and drafts a reply, logs the conversation to HubSpot.
	

5. Unified Timeline
Because every email, WhatsApp message, document, and voice note gets logged to HubSpot by n8n + Claude — the HubSpot contact page becomes the single timeline automatically.
	

6. Document Management
Google Drive with one folder per client. n8n watches the folder 24/7, logs new files to HubSpot, and renames old versions with a date stamp.
	

7. Document Validation
Drop a contract or invoice in a "Validate This" Drive folder. n8n picks it up immediately, Claude reads it, flags missing signatures, blank fields, and unusual clauses, saves a report. Human review still required before relying on it fully.
	

8. Voice Assistant
Record a voice note or meeting, drop the audio file in Drive. Whisper (free, installed on the server) converts it to text. Claude summarises it, lists decisions and action items, and n8n creates the matching HubSpot tasks.
	

9. Workflow Automation
n8n runs a master check every morning on the always-on server — reads emails, WhatsApp, and notes from the last 24 hours, sends them to Claude to extract every commitment and deadline, and creates HubSpot tasks. This now runs reliably with or without anyone's laptop being on.
	



WHAT CHANGED FROM THE ORIGINAL PLAN
Only one real change: the "brain" (Claude) stays exactly the same, but the "always-running engine" moved from Claude Cowork on a personal laptop to n8n. Everything else — HubSpot, Gmail, WhatsApp via Wassenger, Whisper, Drive — works exactly as planned.
	





DAY-BY-DAY 4-WEEK BUILD PLAN
	

Mon–Fri working days. Each week builds on the last. Nothing skipped.


WEEK 1 — CRM + INFRASTRUCTURE FOUNDATION
	

Mon
	Discovery & Setup
• Map out CAR-AGENTS current process: how leads come in, how deals are won/lost
• Define pipeline stages: New Inquiry → Consultation → Car Search → Offer Made → Won/Lost
• Create HubSpot free account, set up company profile
• 🚨 Start WhatsApp Business (WABA) verification with Meta TODAY — this takes 1-2 weeks to approve and will block Week 2 WhatsApp work if not started now
	

Tue
	HubSpot Configuration
• Set up Contacts, Companies, Deals, Tasks, Notes structure in HubSpot
• Build the pipeline with the stages from Monday
• Set up a Private App (OAuth token) in HubSpot for API access — needed for n8n
	

Wed
	Server & n8n Setup
• Rent a small always-on cloud server (e.g. Hetzner, ~€5/mo)
• Install n8n on the server (Docker setup, takes about 1-2 hours)
• Confirm n8n is reachable and stays running 24/7
	

Thu
	Connect HubSpot to n8n
• Add HubSpot credentials (OAuth) inside n8n
• Build and test a simple workflow: create a test contact in HubSpot from n8n
• Confirm read + write both work correctly
	

Fri
	Google Drive Setup
• Create folder structure: CAR-AGENTS Docs / [Client Name] / Contracts, Invoices, Proposals
• Create two special folders: "Validate This" and "Transcribe This"
• Connect Google Drive to n8n, test that n8n can see new files appearing
	

WEEK 2 — COMMUNICATION INTEGRATION
	

Mon
	Gmail / Outlook Setup
• Connect Gmail and Outlook to n8n
• Build workflow: new email arrives → n8n captures sender + content
	

Tue
	Email → HubSpot Logic
• Build matching logic: find contact by email address in HubSpot, or create new one if not found
• Log the email as an activity on the matched contact
• Test with 5-10 real sample emails
	

Wed
	WhatsApp Setup (Part 1)
• Check status of WABA verification started in Week 1 — follow up with Meta if still pending
• Set up Wassenger account on the Enterprise plan
• Connect Wassenger to the WABA number once verified
	

Thu
	WhatsApp Setup (Part 2)
• Connect Wassenger to n8n using their MCP/API integration
• Build workflow: new WhatsApp message → n8n captures sender phone number + message
• Match to HubSpot contact by phone number, log as activity, create new contact if needed
	

Fri
	Testing Communication Layer
• Send test emails and WhatsApp messages, confirm both log correctly to HubSpot
• Fix any contact-matching errors found
• Confirm the Unified Timeline requirement — check a contact page shows both email + WhatsApp together
	

⚠️ TIMELINE RISK FLAG
If Meta's WhatsApp Business verification (started Week 1, Monday) takes the full 2 weeks, WhatsApp work may need to shift slightly later in Week 2. Everything else in Week 2 (email integration) is unaffected and can proceed on schedule regardless.

Fri

Mon
	End-to-End Testing

Fri

BOTTOM LINE
